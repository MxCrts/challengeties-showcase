## What's inside
- **Frontend:** React Native / Expo (SDK 53), TypeScript, EAS builds & OTA updates
- **Backend:** Firebase — Auth (Apple & Google Sign-In), Firestore, Cloud Functions, Storage
- **Monetization:** RevenueCat subscriptions, paywall, entitlements
- **Infra & quality:** Sentry, Firebase Analytics (21-event funnel), push notifications, deep links
- **i18n:** 13 languages including full RTL (Arabic)

## Engineering highlights
- Offline-resilient first-run flow with transactional user-doc creation
- OTA hotfix pipeline (EAS Update) — bug detected in prod → fix live in <4h
- Duo system: invitations, shared progress, server-side reward crediting
